🛍️ E-Commerce Website <br/>
A fully functional, multi-page e-commerce web application built as part of the Software Development Pathway Assessment for the Frontend Developer Challenge.
This project demonstrates proficiency in frontend and backend web development with a clean UI, responsive layout, cart functionality, and order processing flow.

🌐 Live URLs <br/>
Frontend (Vercel): https://azubi-project-ecommerce.vercel.app <br/>
Backend API (Render): https://azubi-project-ecommerce.onrender.com

🚀 Tech Stack <br/>
🧠 Backend:
Node.js,
Express.js,
MongoDB (via Mongoose),
Cloudinary (for image hosting) <br/>
🎨 Frontend: 
Next.js,
Tailwind CSS,
TypeScript,
Redux Toolkit (for state management),

📦 Features <br/>
✅ View a responsive layout optimized for different screen sizes. <br/>
✅ See hover states for all interactive elements. <br/>
✅ Add and remove products from the shopping cart. <br/>
✅ Update product quantities in the cart. <br/>
✅ Complete all required fields during checkout. <br/>
✅ Receive appropriate form validation messages for any missing or incorrect fields. <br/>

✅ VAT calculated at 20% of the product total (excluding shipping) <br/>
